## System Overview
PRAMOD AI is architected as a modular, multi-agent operating daemon. It utilizes a proactive reasoning engine (The Brain) to orchestrate specialized agents across various domains.

## The 10 Layers Explained

1.  **Interface Layer:** Handles all user interactions via Terminal, Mobile (Termux), Voice, and Vision modules.
2.  **Orchestration Layer:** Decomposes complex goals into actionable plans using the Planner Agent.
3.  **Reasoning Engine (Brain):** The core cognitive processor that handles proactive reasoning and decision-making.
4.  **Memory Layer:** Manages context through Short-term, Long-term, and Vector stores for semantic retrieval.
5.  **Execution Layer:** Contains specialized agents like Research, Coding, and Security for task completion.
6.  **Integration Layer:** Securely connects with external services like GitHub and Notion.
7.  **Security Layer:** Implements system-wide encryption and threat detection protocols.
8.  **Analytics Layer:** Monitors system performance and provides feedback for self-improvement.
9.  **Database Layer:** Persists structured and unstructured data for long-term knowledge retention.
10. **Bridge Layer:** Facilitates communication between the core daemon and external mobile/vision hardware.
